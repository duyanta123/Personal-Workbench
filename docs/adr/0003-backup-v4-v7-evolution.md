# ADR 0003：备份 V4–V7 演进

状态：已采用（2026-08-13）

## 决策

备份采用只增不删的版本演进：V4 增加 Inbox，V5 增加周期与习惯模型，V6 增加整数金额和记账实体，V7 增加实体链接、模板和保存视图。当前客户端可导入 V1–V7，缺失字段按对应旧版本默认值规范化；未知更高版本明确拒绝。

恢复继续使用用户数据 revision、`restore_epoch` 和 staging 白名单。新表恢复前按依赖顺序清理，关联引用在写入前验证，旧金额精确转换为整数最小单位。旧恢复函数和旧金额字段在路线图内不删除。

### 补记（2026-08-16，周期任务延期功能）

V7 备份增加 `todo_status_history`（周期任务状态历史：完成/跳过/恢复/延期）。旧版本备份不含该表，恢复后为空表即可，不阻断导入。备份兼容矩阵单测覆盖 V1–V7 全版本交叉导入。
