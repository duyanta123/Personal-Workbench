# ADR 0002：字段级冲突策略

状态：已采用（2026-08-13）

## 决策

更新命令保存被修改字段在编辑开始时的旧值。若 `row_version` 已变化，但这些字段仍等于旧值，则在当前行上应用 patch；否则返回包含当前行和冲突字段的正常业务结果。删除遇到任何版本变化都返回冲突。

本地 outbox 会折叠“创建后编辑”和连续绝对 patch；创建后删除会取消整组未发送命令。依赖的父命令失败、冲突或过期时，子命令进入 failed 并展示原因。

## 不采用

不自动执行 last-write-wins，因为它会静默覆盖另一设备的同字段修改；不上传完整修改历史，冲突摘要只保存在发起设备。
